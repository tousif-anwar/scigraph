# Ablation Experiments

The advanced retrieval ablation compares BM25, dense Word2Vec retrieval, reciprocal-rank fusion, transparent reranking, and graph-aware blending.

Current measured outputs:

- Machine-readable results: `../../reports/results/advanced_retrieval_results.json`
- Human-readable writeup: `../../docs/ADVANCED_RETRIEVAL.md`
- Error analysis: `../../docs/ERROR_ANALYSIS.md`
- Spreadsheet-friendly summary: `../../reports/tables/retrieval_ablation_summary.csv`
- Visualization: `../../reports/figures/retrieval_ablation.png`

The ablation is generated by:

```powershell
python -m scigraph.retrieval.advanced --config configs/dev.yaml
```
